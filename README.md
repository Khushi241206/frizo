# Frizo Meal Planner

Create a mobile app called "Frizo – Your Daily Meal Partner"

Goal:

Help students save money, plan meals, and manage groceries easily.

Core Features:

- Budget tracking with alerts

- Smart meal suggestions (based on budget & preference)

- Indian recipes (simple, student-friendly)

- Weekly meal planner (7 days: breakfast, lunch, dinner)

- Pantry tracking

- Auto-generated grocery list

- Grocery ordering section

- Payment page for orders

- Savings tracker (“You saved ₹200 🎉”)

User Flow:

Onboarding (budget + preference) → Home (today’s meal) → Weekly meal plan (7 days meals) → Recipes → Auto grocery list → Grocery section → Payment → Track savings

Design:

- Orange Gen Z theme (bold, fun, modern)

- Clean card-based UI with smooth animations

- Simple navigation (Home, Plan, Groceries, Profile)

Extras:

- Daily streaks & fun notifications

- Fast, minimal steps experience

Important:

- Remove nearby restaurant option

- Focus only on meal planning, recipes, and groceries

Goal:

Make it simple, addictive, and a startup-level MVP for students.
